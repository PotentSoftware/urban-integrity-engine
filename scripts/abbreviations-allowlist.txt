# abbreviations-allowlist.txt — tokens exempt from scripts/check-abbreviations.sh (NAV-04, D-04).
#
# check-abbreviations.sh extracts every 2-to-6-letter all-caps token found inside a Rust string
# literal under crates/workbench-web/src and requires each one to be either (a) a genuine
# abbreviation defined in docs/abbreviations.md's glossary sections, or (b) listed here. A token
# lands here for one of two reasons:
#
#   1. It is not really an abbreviation at all — it's a plain English word, verdict label, or
#      test fixture that happens to be all-caps and 2-6 letters (e.g. "OK").
#   2. It IS a genuine abbreviation, defined in docs/abbreviations.md, but the guard's simple
#      awk-based glossary extraction (`\*\*[A-Z0-9]{2,6}\*\*`) does not catch it because the
#      glossary entry is a compound token (e.g. "HTTP/HTTPS") rather than a bare `**TOKEN**`.
#
# One token per line. Blank lines and lines starting with '#' are ignored.

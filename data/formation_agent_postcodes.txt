# Format: one postcode per line. Blank lines and text after `#` are ignored.

# CURATION POLICY (load-bearing — read before editing):
#   * Exact match only. Never fuzzy, never partial — this mirrors the app-wide
#     exact-match-only policy.
#   * Each entry permanently suppresses fraud alerts at that postcode. Under-
#     suppressing (a noisy false alert) is far safer than over-suppressing (a
#     hidden real cluster). When in doubt, LEAVE IT OUT.
#   * Only add a postcode you can confirm is a formation-agent / virtual-office
#     building — not merely a shared or serviced office with some co-tenants.
#   * Do NOT add by building name. "International House" alone names 7 distinct
#     real buildings in different cities; a name is not an address.
